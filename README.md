# AdamAI — презентация продукта

Десктопная скролл-презентация ИИ-помощника «AdamAI» (карандаш на рабочем столе).

**Онлайн:** https://adam-ai-desktop.vercel.app

## Структура проекта
```
index.html          — разметка всех слайдов («глав»)
styles.css          — все стили (десктоп + узкие экраны ≤1060px)
styles-noscript.css — фолбэк: без JS всё разомкнуто в длинную страницу
js/data.js          — данные: FINISHES (корпуса карандаша) и STATES (состояния)
js/main.js          — логика: волновой скролл-дек, кнопка «К началу»,
                      лайтбокс скриншотов, смены корпуса/состояния
assets/             — скриншоты интерфейса (JPEG)
favicon.svg         — иконка-карандаш
vercel.json         — конфиг деплоя Vercel (кэш для assets/js/css)
```

## Функции
- волновой скролл: главы сменяются волной, плавно «дос выключаются» при остановке;
- плавающая кнопка «К началу» справа снизу — возврат к первому слайду (на узких экранах скрыта);
- тёмная/светлая тема: переключатель в шапке, выбор запоминается в localStorage;
- состояния и корпус карандаша переключаются кнопками на слайдах;
- лайтбокс для скриншотов, эффект «Обвести».

## Локально
Открой папку в VS Code и запусти любой статический сервер, например `python -m http.server` — или просто открой `index.html` двойным кликом.

## Деплой
Статический сайт без сборки. Каждый `git push` в `main` автоматически обновляет Vercel.

## Технически
Чистый HTML/CSS/JS без сборки и зависимостей. Исходник страницы мобильной версии — в приватном репозитории `adam-ai-mobile`.
