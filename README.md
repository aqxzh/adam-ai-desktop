# AdamAI — презентация продукта

Десктопная скролл-презентация ИИ-помощника «AdamAI» (карандаш на рабочем столе).

**Открыть онлайн:** https://aqxzh.github.io/adam-ai-desktop/

## Что внутри
- весь сайт в одном файле `index.html` (~6,6 МБ): скриншоты интерфейса и карандаш вшиты внутрь;
- волновой скролл: главы сменяются волной, плавно «дос выключаются» при остановке;
- состояния карандаша переключаются кнопками в блоке «Интуитивный интерфейс»;
- выбор корпуса у карандаша, лайтбокс для скриншотов, ответы по «Обвести».

## Локально
Скачайте `index.html` и откройте двойным кликом — интернет не нужен.

## Технически
Чистый HTML/CSS/JS без сборки и зависимостей. Исходник страницы мобильной версии — в приватном репозитории `adam-ai-mobile`.
